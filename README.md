# 🏫 Campus Navigation System

A shortest-path routing application built for university campuses using Graph Data Structures and Dijkstra's Algorithm.

---

## 💡 How It Works

* **Campus Model:** Buildings are represented as **Nodes** (Main Gate, Library, CSE Block, Canteen, etc.).
* **Road Network:** Pathways and distances in meters are represented as **Weighted Edges**.
* **Shortest Path Calculation:** Dijkstra's Algorithm calculates the optimal route dynamically.
* **Graph Visualization:** Visualizes the campus network showing graph nodes and road distances.

---

## 🛠️ Technologies Used

* **Python 3**
* **NetworkX** (Graph Data Structure)
* **Matplotlib** (Graph Plotting & Visualization)
* **Heapq** (Min-Heap Priority Queue)
* **Dijkstra's Algorithm**
